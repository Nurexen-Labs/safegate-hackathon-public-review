## Important boundary

These are historical, commit-pinned review packages.

They do not:

- expose SafeGate private Core
- expose credentials or wallet secrets
- initiate payments
- deploy infrastructure
- mutate databases
- modify historical hackathon submissions
- claim stronger assurance than the original evidence supports
